# חיבור משתמשת עם אנדרואיד (Health Connect)

המסלול: **שעון (שיאומי, סמסונג, גרמין…) → האפליקציה של השעון → Health Connect → Health Agent Sync → השרת**.

Health Agent Sync היא אפליקציה שלנו (הקוד ב-`android/`), בלי תשלום ובלי צד שלישי. היא קוראת מ-Health Connect ושולחת לשרת כל 30 דקות, ובכל פעם את 48 השעות האחרונות. השרת מעדכן ולא משכפל, ולכן גם נתונים שמגיעים באיחור (כמו שינה) נקלטים.

---

## 1. בצד שלך (מנהלת הפרויקט), ב-Supabase

### א. יצירת משתמשת
**Authentication → Users → Add user** עם המייל שלה. הפרופיל נוצר אוטומטית. ה-ID שלה מופיע ברשימה.

### ב. טוקן לאפליקציה (SQL Editor)
```sql
select * from public.create_ingest_source('<ה-ID שלה>', 'health_connect', 'גלקסי');
```
התוצאה כוללת `token` שמתחיל ב-`hk_`. הוא מוצג **פעם אחת בלבד**, ובשרת נשמר רק hash שלו. מעבירים אותו אליה בערוץ פרטי.

### ג. קוד קישור לטלגרם (SQL Editor)
```sql
select public.create_telegram_link_code('<ה-ID שלה>');
```
קוד של 6 ספרות, תקף ל-15 דקות.

---

## 2. בטלפון שלה

### א. Health Connect
בגלקסי עם Android 14 ומעלה הוא מובנה: **הגדרות → אבטחה ופרטיות → פרטיות → Health Connect** (או חיפוש "Health Connect" בהגדרות). ב-Android 13 ומטה: להתקין את Health Connect מ-Google Play.

### ב. האפליקציה של השעון כותבת ל-Health Connect
ב-**Mi Fitness**: פרופיל → הגדרות → Health Connect → לאשר כתיבה של צעדים, דופק, שינה, אימונים ומשקל.
(Samsung Health: הגדרות → Health Connect. גרמין: Garmin Connect → הגדרות → Health Connect.)

### ג. התקנת Health Agent Sync
1. להעביר אליה את הקובץ `HealthAgentSync-1.0.0.apk` (בוואטסאפ, במייל או ב-Drive).
2. לפתוח את הקובץ בטלפון. בפעם הראשונה אנדרואיד יבקש לאשר "התקנה ממקורות לא ידועים" לאפליקציה שממנה פתחה את הקובץ (וואטסאפ, Files וכו'). מאשרים, וממשיכים בהתקנה.
3. Google Play Protect עלול להזהיר שהאפליקציה לא מוכרת, כי היא לא מגיעה מהחנות. לבחור **"התקנה בכל זאת"**.

### ד. הגדרה באפליקציה
1. **כתובת השרת:** כבר ממולאת.
2. **טוקן:** להדביק את ה-`hk_...` שקיבלה ← **שמירה**.
3. **מתן הרשאות ב-Health Connect** ← לאשר הכול, **כולל "גישה לנתונים ברקע"** ו**"גישה לנתונים מהעבר"**. בלי הרשאת הרקע הסנכרון האוטומטי לא יעבוד.
4. **סנכרון עכשיו.** הסנכרון הראשון שולח 30 יום אחורה, ויכול לקחת דקה. בסוף מופיע "✅ סונכרן".

### ה. כדי שהסנכרון ברקע לא ייעצר (חשוב בגלקסי)
סמסונג "מרדימה" אפליקציות שלא נפתחות. כדאי:
**הגדרות → אפליקציות → Health Agent Sync → סוללה → ללא הגבלה**.
וגם לוודא שהיא לא ברשימת "אפליקציות במצב שינה" (הגדרות → טיפול במכשיר → סוללה → הגבלות שימוש ברקע).

### ו. טלגרם
לפתוח את הבוט ולשלוח `/start 123456` עם הקוד שקיבלה.

## 3. בדיקה

ב-Supabase, **Table Editor → `ingest_events`**: לכל חלון של יומיים אמורה להופיע שורה עם `status = processed`. בעמודה `stats` רואים כמה דגימות, לילות ואימונים נכנסו, וב-`warnings` מה לא זוהה.

**מה לא יגיע משיאומי דרך Health Connect** (מגבלה של Mi Fitness, לא שלנו): מסלולי GPS, הקפות וספליטים. HRV תלוי בדגם, ואם הוא לא מגיע, ציון ההתאוששות נשען על דופק במנוחה ושינה.

---

## עדכון גרסה של האפליקציה
הקובץ חתום במפתח של סביבת הבנייה. אם גרסה חדשה נבנתה במפתח אחר, אנדרואיד לא יאפשר "עדכון" מעל הקודמת: מסירים את הישנה, מתקינים את החדשה, ומזינים שוב את הטוקן. הנתונים בשרת לא נפגעים. סנכרון הפתיחה שולח שוב 30 יום, ושליחה חוזרת לא יוצרת כפילויות.

## בנייה מחדש מהקוד
```bash
cd android
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew assembleDebug        # → app/build/outputs/apk/debug/app-debug.apk
```
